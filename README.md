# 📱 PhoneCheck - تطبيق فحص الهاتف

تطبيق أندرويد لفحص شامل للهاتف: الجهاز، البطارية، الذاكرة، الشبكة، الشاشة، الحساسات، واستهلاك التطبيقات للبيانات.

## ✨ الميزات

- 📱 معلومات الجهاز (الطراز، المعالج، النظام)
- 🔋 فحص البطارية (النسبة، الحرارة، الجهد، الصحة)
- 💾 فحص الذاكرة والتخزين (RAM، داخلي، خارجي)
- 📡 فحص الشبكة (WiFi، بيانات الجوال)
- 🖥️ فحص الشاشة (الدقة، الكثافة، معدل التحديث)
- 🧭 فحص الحساسات
- 📊 فحص استهلاك التطبيقات للبيانات

## 🛠️ التقنيات

- **اللغة:** Kotlin
- **Min SDK:** 24 (Android 7.0)
- **Target SDK:** 34 (Android 14)
- **المكتبات:** AndroidX, Material Design, CardView, RecyclerView
